Risks / Challenges



Mitigation Strategy

30 m DEM mayunder resolve steep Himalayan terrain.
Delft3D GUI requiresDeltares registration.
Large simulation outputscan stress browserdashboard.
Live dem breach datais sensitive.
Refine terrain locally near 
Dam using high-res DEM(Stereo/SRTM.
Use open-source Delft3D
FM kernels directlyvia scripting / API.
Serve tiled Cloud-OptimizedGeoTIFFs, paginate data &use vector tiles.
  Use only publicly availabledata and follow datasharing policies.
